# Alysson Portela — Portfólio

Portfólio de uma página para apresentar:
- Edição de vídeo
- Thumbnails
- Shorts/Reels
- Apoio criativo e bastidores

## Arquivos
- `index.html` — estrutura da página (conteúdo principal)
- `style.css` — visual e responsividade
- `script.js` — animações e lightbox
- `assets/` — thumbnails e imagem de referência
